# King Kong PC Port: beta builds

This repository only holds **beta builds** of the [King Kong PC Port](https://github.com/TekRantGaming/king-kong-recompiled). There is no code here.

Betas are early test builds of upcoming features. They can have bugs, and support for them is limited. **For the stable version, use the [main project](https://github.com/TekRantGaming/king-kong-recompiled/releases/latest).**

## How to get the beta

You don't need to download anything from here. In the port's launcher:

1. Go to **About**
2. Choose **Change version**, then **Beta**
3. Read the warning and press **I understand, switch to beta**

The launcher downloads the newest beta and restarts. Your saves and settings are kept. To go back, do the same and choose **Stable**.

## Good to know

- **No game files are included.** You need your own copy of the Xbox 360 game, as with the stable version.
- Windows only for now.
- Please report how the beta runs on the [Discord](https://discord.gg/PET2xU5FJq).
